# RAG Project

This project implements a Retrieval-Augmented Generation (RAG) system using Python and LangChain.

## Setup

1. Create virtual environment

python -m venv venv

2. Activate environment

venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

## Run

python main.py
